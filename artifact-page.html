这是什么

          
一个完整的教学用工具链：内置的 C++ 子集编译器 把源码编译成 x86-32 / x86-64 / ARM32 / ARM64 四种真实指令集的汇编，
             再由 指令级 CPU 模拟器 逐条执行，实时显示寄存器、标志位、栈内存、数据段以及数据通路各阶段的变化。

          
操作

          
    
            
  • 编译装载（Ctrl+Enter）：编译当前源码并复位 CPU
    • 
            
  • 单步（F10）：执行一条机器指令，所有发生变化的寄存器/内存会高亮闪烁
    • 
            
  • 运行 / 暂停（F5）：按所选速度连续执行；点击汇编行号可设断点
    • 
            
  • 顶部切换架构后会自动重新编译，可直接对比同一段 C++ 在不同 ISA 上的实现
    • 
          

          
支持的 C++ 子集

          
    
            
  • 类型：int、char、bool、指针 T*、一维数组 T a[N]
    • 
            
  • 全局变量（可带初始化列表）、局部变量、函数（支持递归）
    • 
            
  • 语句：if/else、while、do-while、for、break、continue、return
    • 
            
  • 运算：+ - * / %、比较、&& || !、位运算 & | ^ ~ << >>、++ --、复合赋值、取地址与解引用
    • 
            
  • 输出：cout << 表达式 << endl;（字符串常量、整数），或 print_int() / print_str()
    • 
            
  • #include 与 using namespace std; 会被忽略，可以照常书写
    • 
          

          
模拟范围说明

          
模拟器在指令语义层工作：忠实执行每条指令对寄存器、内存、标志位的影响，遵循各架构真实的调用约定
             （System V AMD64、cdecl、AAPCS、AAPCS64）与栈帧布局；但不模拟指令编码字节、缓存、流水线冲突与乱序执行，
             指令地址按 4 字节等距排列。除法、取模、指针缩放等处的架构差异都是真实的（例如 x86 的 idiv 对应 ARM 的 sdiv + msub/mls）。
